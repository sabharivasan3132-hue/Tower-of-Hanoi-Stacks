# Tower of Hanoi using Stacks

## Description
This project solves the classic Tower of Hanoi puzzle using three stacks to represent the pegs.

## Problem Statement
Move all disks from source peg to destination peg using an auxiliary peg, following rules:
1. Only one disk can be moved at a time
2. A larger disk cannot be placed on a smaller disk

## Concepts Used
- Stack (LIFO)
- Recursion
- Data Structures

## How it works
Three stacks represent the three pegs. Disks are moved between stacks following the rules using a recursive approach.

## Example
For 3 disks:
Move disk 1 from A to C  
Move disk 2 from A to B  
Move disk 1 from C to B  
...
